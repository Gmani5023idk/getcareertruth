## How to Run the Tests

### Prerequisites
1. **Environment Variables**: Ensure `.env` or `.env.local` exists with:
   ```bash
   DATABASE_URL=postgresql://...
   NEXTAUTH_SECRET=...
   GOOGLE_CLIENT_ID=... (for OAuth tests)
   RESEND_API_KEY=... (for email tests)
   ```

2. **Database**: Prisma migrations must be applied:
   ```bash
   npx prisma migrate deploy
   ```

3. **Development Server** (optional, for API endpoint tests):
   ```bash
   npm run dev
   # Server must run on http://localhost:3000
   ```

### Running Tests

#### Option 1: Run All Agents
```bash
cd /home/manikanta/hermes/getcareertruth
npm test -- tests/agents/ --verbose
```

#### Option 2: Run Individual Agent
```bash
# Agent 1: DB Connectivity
npm test -- tests/agents/agent-1-db-connectivity.test.ts

# Agent 2: Credentials Registration
npm test -- tests/agents/agent-2-registration-credentials.test.ts

# Agent 3: OAuth Registration
npm test -- tests/agents/agent-3-registration-oauth.test.ts
```

#### Option 3: Run with Coverage
```bash
npm test -- tests/agents/ --coverage
```

## Cleanup Behavior

All test files include automatic cleanup in `afterAll` hooks:

1. **Test Users Deleted**: All users with email matching `testuser_*`, `student_*`, `oauthuser_*`, etc.
2. **Associated Records**: Account, Session, and profile records deleted via cascade
3. **Cleanup Report**: Console output shows count of deleted records
4. **Production Safety**: Tests should check `process.env.NODE_ENV` before mutation

## Security Rules Implemented

✅ **Never log secrets**: DATABASE_URL, NEXTAUTH_SECRET, RESEND_API_KEY masked
✅ **Mask emails in reports**: `testuser_12345_xxxxx@example.com` → `t***@example.com`
✅ **No production writes**: Tests skip or use read-only mode in production
✅ **Password hashing verified**: All credential tests validate bcrypt format (`$2a$`, `$2b$`, `$2y$`)
✅ **SQL injection protection**: Prisma parameterized queries used throughout
